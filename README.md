# serkanberksoy/tap

Homebrew formulas for [blackglass](https://github.com/serkanberksoy/blackglass),
a note-taking workspace for the terminal.

```bash
brew install serkanberksoy/tap/blackglass
```

Or tap once and install by name:

```bash
brew tap serkanberksoy/tap
brew install blackglass
```

blackglass is built from source (Rust is installed for the build), on
macOS and Linux. Then take the tour: `blackglass --example`.

The formula is written for each release by blackglass's
`scripts/homebrew-formula.sh`.
